# shopify_sales
Shopify Sales & Customer Funnel Analysis Dashboard (Power BI)

This project presents an interactive Shopify Sales & Customer Funnel Dashboard built in Power BI to analyze sales performance, customer behavior, retention metrics, and regional trends. The dashboard transforms raw Shopify transaction data into actionable business insights through dynamic KPIs, geospatial analysis, customer segmentation, and sales trend monitoring.
